# Танки: 8-битный рогалик

Роглайк-танчики в духе Battle City на чистом HTML5 Canvas + JavaScript. Процедурные карты, улучшения после каждого сектора, 4 биома, 4 босса и кооператив на одной клавиатуре.

## Запуск

Открыть `index.html` в браузере — сборка и сервер не нужны.

## Управление

| | Движение | Огонь | Спецприём |
|---|---|---|---|
| 1P | WASD | Пробел | E |
| 2P | Стрелки | Enter / Num0 | K / Num1 |

`Esc`/`P` — пауза, `M` — музыка. Поддерживаются геймпады.

## Боссы

1. **Голиаф** — сверхтяжёлый танк, давит кирпич и таранит.
2. **Стрекоза** — боевой вертолёт: ракеты, пулемёт, бомбардировка.
3. **Сколопендра** — механический червь из сегментов, умеет зарываться.
4. **Цитадель Омега** — крепость с турелями, щитом ядра и лазером.
